## How to Use This File

This is the seed data for Phase 0's directory. It contains 25 RV parks
and campgrounds and 10 service providers along the I-15 corridor.

**Before publishing any listing:**

1. Verify the address, phone, and website. Many are from memory and may
   be outdated.
2. Replace placeholder phone numbers (555-xxxx) with real numbers or
   remove them.
3. Add a 1–2 sentence description in the "Notes" field. Keep it factual.
   No marketing voice.
4. If a listing can't be verified, cut it. Better to launch with 15 real
   listings than 25 questionable ones.

**What this file is not:**

- Not reviews. Reviews come in Phase 1.
- Not ratings. Ratings come in Phase 1.
- Not a complete list. This is a seed. It grows.
