## The One-Sentence Version

A verified-review directory for RV parks and service providers on one
corridor, with a help form that routes to real humans.

---

## What's In

### Places

- RV parks and campgrounds
- Dimensional ratings (not just stars):
  - Big-rig access
  - Hookup quality (electric, water, sewer)
  - Cell signal (by carrier)
  - Wi-Fi quality
  - Noise level
  - Safety / security
  - Site spacing
  - Value for money
  - "Would I stay again?"
- Written reviews with photos
- Upvote/downvote on individual reviews ("Was this useful?")
- Filter by rig type (so a 45-foot owner sees reviews from other big rigs)

### Help

- Service provider directory:
  - Mobile RV repair
  - Towing
  - Storage
  - Mobile detailing
  - Inspectors
- Same review system as parks
- "Get help now" form:
  - Name, email, phone
  - Location (free text: city, park name, mile marker)
  - Problem type (dropdown)
  - Urgency (emergency / scheduled)
  - Consent checkbox
  - Routes to 1–2 providers, not a blast list
- "I can take jobs" form for providers to opt in

### The Homepage

- Manifesto in the first screen
- Waitlist signup
- "I need help" / "I can help" buttons
- Link to Trust Covenant in footer

## The Corridor

**Primary:** I-15 (San Diego → Las Vegas → Salt Lake City → Montana)
**Alternative:** I-10 (LA → Phoenix → Tucson → El Paso → Florida)

I-15 is the recommendation because:

- Las Vegas is a natural node (heat kills ACs, tourists break down)
- It's a major RV corridor
- It's geographically contained
- The founder already has Vegas research
