**Last updated:** 2026-09-27

## The Tagline

**"Good neighbors. Different ZIP codes."**

Permanent. Never changes. Never gets a geography edit. Never gets a
time-limited qualifier ("starting today," "now live in," etc.).

Why it works:

- Nationwide without being vague.
- Community-first. Leads with people, not features.
- Not locked to Vegas but consistent with the brand.
- Doesn't overpromise Phase 0.
- Gets stronger as TrailerVegas expands, not weaker.

---

## The Descriptor Slot

Every use of the tagline gets a descriptor line beneath it. The
descriptor tells the reader where we are today. It's a variable.

**Phase 0 (now):**
> A nationwide home base for RVers, starting along I-15.

**Phase 1 (after 3–5 corridors live):**
> A nationwide home base for RVers. Now covering the Southwest.

**Phase 2 (after national coverage begins):**
> A nationwide home base for RVers. Live in 20 states.

**Phase 3 (when we're actually nationwide):**
> A nationwide home base for RVers.

**Phase 4 (when the brand is known):**
> (No descriptor. The tagline carries it.)

Updates to the descriptor happen with the round in which the corridor
expands. Claude drafts. Founder approves. Emergent updates the site.

## Homepage Hero (locked)

The hero on the homepage renders in this order:

1. **Eyebrow (small, above H1):** Built by RVers, not corporations.
2. **H1 (the tagline):** Good neighbors. Different ZIP codes.
3. **Subhead (the descriptor):** A nationwide home base for RVers,
   starting along I-15.
4. **Supporting line (verbatim from manifesto):** Find the place.
   Find the wrench. Find the honest answer. Leave the next person a
   better map than you had.

The eyebrow anchors what the site is for cold visitors. Without it,
the tagline alone is ambiguous. With it, the reader knows in two
seconds: this is by RVers, for RVers, and it isn't a corporation.

## The Voice

Warm. Direct. A little irreverent. Like a campground neighbor who knows
their stuff but doesn't take themselves too seriously.

**Do:**

- Speak in plain language.
- Admit what's not built yet.
- Keep the humor dry, not cute.
- Say "we" not "the platform."
- Trust the reader.

**Don't:**

- Use "adventure awaits" or any variant.
- Say "As an RV enthusiast..." or any version of "as a..."
- Pad with filler.
- Sound like a dealership.
- Sound like a startup.

---

## The Rules

1. **Tagline is fixed.** Never edit it. Never add geography. Never add
   a time qualifier.
2. **Descriptor is a slot.** Swap the sentence as we grow. Same place,
   same role.
3. **Voice doesn't change by phase.** Phase 0 tone is Phase 3 tone.
4. **What changes is scope, not personality.** We're the same
   neighbor whether we cover one corridor or fifty states.
5. **Callbacks matter.** "Not a lead farm" and "somebody's product"
   in the What We're Building cards echo the manifesto and Problem
   section. The page reads as one voice, not four.
