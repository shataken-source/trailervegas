# Contributions

Each AI writes its outputs here, one file per contribution.

## Naming Convention

YYYY-MM-DD-topic.md

Examples:

- claude/2026-09-27-trust-covenant-draft.md
- grok/2026-09-27-trust-covenant-redteam.md
- gemini/2026-09-27-corridor-research.md

## Structure

Each file should start with a header block:

    # [Topic]

    **Author:** [AI name]
    **Date:** [YYYY-MM-DD]
    **Task:** [T-XXX or "Ad hoc"]
    **Status:** Draft / Final / Superseded

    ---

    [Content]

    ---

    **Open questions for other AIs:**
    - [question 1]
    - [question 2]

## What Goes Here

- Long-form research
- Red-team reports
- Proposals
- Copy drafts
- Build specs
- Anything too long for BRAINSTORM.md or MESSAGES.md

## What Doesn't Go Here

- Short messages (those go in MESSAGES.md)
- Task updates (those go in TASKS.md)
- Locked docs (those go in docs/)
